# 대부호 (President) 3D 테이블

브라우저에서 하는 대부호(대빈민) 카드게임입니다. `index.html` 파일 하나로 동작하고, 구라 3D 테이블 게임의 3D 테이블·방 시스템·봇·이모티콘·효과음을 그대로 가져와 규칙만 대부호로 바꿨습니다.

## 실행

- `index.html`을 브라우저로 열면 됩니다. 3D 화면(three.js)과 온라인 방(PeerJS)은 CDN에서 불러오므로 인터넷 연결이 필요합니다.
- **봇과 연습**: 로비의 "봇과 연습"은 방장 엔진만 쓰므로 PeerJS 서버 없이 혼자서 시작할 수 있습니다.
- **온라인**: "방 만들기"로 4자리 코드를 만들어 친구에게 알려 주면 됩니다. 방장 브라우저가 규칙을 처리합니다. 공개 방 목록, 새로고침 뒤 재접속, 방장 이양은 구라 게임과 같습니다. (방 이름은 구라 게임과 겹치지 않게 `president-` 접두사를 씁니다.)
- GitHub Pages 등 정적 호스팅에 올려도 그대로 동작합니다.

## 모바일 홈 화면에 추가

HTTPS로 호스팅한 주소(예: GitHub Pages)에서 열어야 합니다. `file://`로 연 경우에는 설치되지 않습니다.

- **안드로이드 크롬**: 메뉴(⋮) → "홈 화면에 추가" 또는 "앱 설치".
- **아이폰 사파리**: 공유 버튼 → "홈 화면에 추가".

홈 화면 아이콘으로 열면 주소창 없이 전체화면으로 시작합니다. `manifest.webmanifest`, 아이콘(`icon-*.png`, `apple-touch-icon-180.png`), `sw.js`(앱 껍데기 캐시, `index.html`은 네트워크 우선)가 이를 담당합니다. 새 버전을 올리면 다음 접속에 반영되고, 바뀌지 않으면 `sw.js`의 `CACHE` 이름 끝 숫자를 올리세요.

## 규칙

- 트럼프 52장 + 조커(0~2장). 강약: 3 < 4 < … < K < A < 2 < 조커, 무늬는 강약과 상관없습니다.
- ♦3을 가진 사람이 먼저 냅니다. 한 장 또는 같은 숫자 여러 장을 내고, 다음 사람은 같은 장수로 더 강한 카드를 내거나 패스합니다.
- 남은 사람이 전부 연달아 패스하면 판이 끝나고 마지막에 낸 사람이 새로 시작합니다.
- 조커는 와일드 카드(다른 숫자 대신)이고 혼자 내면 가장 강합니다.
- 끝까지: 먼저 털어낸 순서대로 대부호 → 부호 → 평민 → 빈민 → 대빈민. 빠른 모드는 1등이 나오면 끝납니다.

방 설정에서 켜고 끌 수 있는 규칙:

| 규칙 | 내용 |
| --- | --- |
| 8 끊기 | 8을 내면 판이 즉시 끝나고 낸 사람이 다시 시작 |
| 혁명 | 같은 숫자 4장 이상을 내면 강약이 뒤집힘 (한 번 더 나오면 원래대로) |
| 계단 | 같은 무늬 연속 숫자 3장 이상 |
| 묶기 | 같은 무늬 구성이 연달아 나오면 그 판은 그 무늬만 가능 |
| 11 백 | J를 내면 그 판 동안 강약이 뒤집힘 (혁명과 겹치면 상쇄) |
| 계급 카드 교환 | 다음 판 시작 전 대빈민↔대부호 카드 교환 (4명 이상이면 2장, 빈민↔부호 1장). 대빈민은 가장 강한 카드를, 대부호는 가장 약한 카드를 자동으로 줌 |

## 구조

`index.html` 안에 모두 들어 있습니다.

- **규칙 함수** (`parseCombo`, `playError`, `legalPlays`): 방장 엔진과 화면이 같이 씁니다. 내 차례에 낼 수 있는 카드에는 빨간 점이 뜨고, 낼 수 없는 조합은 내기 버튼에 이유가 표시됩니다.
- **호스트 엔진** (`doPlay`, `doPass`, `newTrick`, `doExchange`, `botTurn`): 방장 브라우저에서만 돌고, 참가자에게는 자기 손패만 담긴 상태를 보냅니다.
- **봇**: 쉬움/보통/어려움. 어려움은 강한 카드를 아끼고, 혁명이 유리할 때만 쓰며, 상대 카드가 2장 이하면 패스하지 않습니다.
- **3D 테이블**: 가운데에는 지금 깔린 조합만 앞면으로 펼쳐지고, 다른 사람 손패는 카드 뒷면 더미로 보입니다.

## 테스트

```
node tests/engine.test.js
```

`index.html`에서 규칙·엔진 코드만 잘라 실행합니다. 규칙 판정 단위 테스트와, 봇끼리 150가지 설정(2~8명, 규칙 켜고 끄기, 조커 수, 빠른 모드, 4판 연속 교환 포함)으로 약 5만 수를 두어 멈춤·반칙·순위·카드 수를 확인합니다.

구라 3D 테이블(속고 속이는 카드게임) 코드에서 출발했습니다. 구라 전용 요소(구라! 외치기, 자음 카드, 선언 휠)는 제거했습니다.
